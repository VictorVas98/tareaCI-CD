Descripción:

Este proyecto consiste en el desarrollo e implementación de una aplicación web básica diseñada para demostrar el funcionamiento de un flujo de integración y 
despliegue continuo utilizando herramientas de nube. La aplicación fue construida con el lenguaje de programación Python y el microframework Flask, lo que 
permitió generar una interfaz sencilla que funciona de manera integral con procesos de automatización.

El núcleo de la práctica se centra en la conexión entre un repositorio de GitHub y un servicio de App Service en Azure, donde a través de la configuración de 
GitHub Actions se estableció un mecanismo que detecta automáticamente cualquier cambio realizado en el código fuente. Al realizar una actualización mediante un 
comando de envío al repositorio, el sistema inicia un proceso de construcción y despliegue hacia la infraestructura de Azure sin necesidad de intervención manual.
